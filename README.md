# Projet Dossier Community

## Contexte

Ce projet est réalisé dans le cadre de la formation CDA de Simplon. Il est destiné à être utilisé par Simplon.  
Il sera développé tout au long de la formation, en suivant les différents modules d'apprentissage abordés.  
Le dossier sera présenté au jury afin qu'il puisse s'informer et connaître tous les détails du projet qui leur sera présenté.

## Objectifs

Le but de ce dossier est de mettre en évidence :

- La liste des compétences mises en œuvre dans le cadre du projet, validant les compétences professionnelles listées dans le REAC CDA.
- L’expression des besoins du projet.
- L’environnement technique utilisé pour le projet.
- Les réalisations permettant la mise en œuvre des compétences.
